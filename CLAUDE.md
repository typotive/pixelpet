# Desktop Pet — project reference

Read this before touching `desktop_cat.py` (~6,100 lines). Jump to code by searching for
the class or function names below; line numbers drift, names don't.

## What it is
A pixel-art cat (PyQt6, falls back to PySide6) that lives above the Windows taskbar or macOS Dock
(**Mac support is untested on a real Mac**; see Mac notes below):
- **Health nudges:** never sit more than **40 min** straight (get up and walk; a 5+ min break resets it); water every 30 min of
  screen time; lunch at 13:00; go home at 17:45. All editable, and the user can add their own routines.
- **Six pets, five sizes, eleven colours, an optional second pet:** tabby cat, golden retriever, hamster, bunny, penguin, caped hero (original character; does a grapple-and-fly stunt). Seasonal hats, mood (hearts / sulking), treats and a ball game, hops onto the active window's top edge.
- **Productivity:** focus timer (25/5), quick notes and one-off reminders ("call bank at 4pm"), 20-20-20 eye break, a calculator and unit converter in Fetch, pinned and recent files, Open with…, clipboard history (memory only), global hotkeys, screenshot helper, daily summary and a weekly chart, quiet while a full-screen app runs, light/dark glass, optional per-pet sounds.
- **Double-click → choice bubble:** 🔎 Fetch, 🍅 Focus, 📝 Note, 🐾 Play, 📸 Screenshot, 🐍 *Cobra mode* (empty the Recycle Bin and old temp/cache files, after
  confirmation), ⚙ Settings. While the cleanup runs, a pixel cobra rises in front of the pet and the
  pet smashes it ("POW!"). When it's done, the cobra keels over with XX eyes and fades out.
- Single file, no build step. **No exe needed:** the shortcut runs it with `pythonw`.

## Run / commands
```
python desktop_cat.py                     # normal
python desktop_cat.py --demo              # fast timers: sitting limit 30 s, idle 20 s, water 45 s
python desktop_cat.py --install-shortcut  # (re)create .ico + Desktop/Start-menu shortcuts
--alert-minutes N  --idle-minutes N  --idle-policy reset|pause  --scale N
--index PATH (repeatable)  --water-minutes N  --lunch HH:MM  --home HH:MM
```
A second launch pings the running cat (it says "I'm already here!") and exits.
Needs Python 3.10+ with PyQt6 (`pip install -r requirements.txt`).
Flags beat `settings.json` for that run (`cfg.overrides`), and **nothing is saved while any such flag is set**, so `--demo` timers can't leak into the saved settings.
Right-click menu: status, Fetch, Clipboard history, Notes, Focus, Screenshot, Play ▸ (treat, ball), Today's summary, Cobra, Reset timer, Preview reminders ▸ (Walk, every routine, **Cobra fight practice**, which deletes nothing, and **Hero stunt** when the hero is the pet), Settings, Rebuild index, Quit. Menu items show the shortcut actually registered.
Global hotkeys (Windows): Ctrl+Alt+Space (falls back to Ctrl+Alt+F if another app has it, which is the case on the owner's PC) = Fetch, Ctrl+Alt+V = clipboard history, Ctrl+Alt+N = notes.

## Mac notes
Tested only by simulation on Windows (`os.sep = "/"` before import, patched `sys.platform`, inspecting the `.app` output) plus `bash -n` on the installer. Never run on a real Mac.
- Paths use `SEP`, never a literal backslash. `Query` accepts `/` or `\` in path terms.
- `WA_MacAlwaysShowToolWindow` keeps the windows visible when another app is active.
- No screen grabbing (`_refresh_backdrop` returns early): it would trigger the Screen Recording prompt, so glass is a plain tint.
- Idle time comes from `CGEventSourceSecondsSinceLastEventType`. Finder reveal uses `open -R`. Apps come from `mac_app_bundles`.
- Index root is the home folder, without `~/Library` or `.Trash`. No live watcher, so it refreshes on the `index_max_age_min` rescan at launch.
- Cobra has no default folders on a Mac, so it reports nothing to clean. Windows folders are only added on Windows, which also stops an empty `LOCALAPPDATA` from producing a relative `Temp` path.
- The Dock may show a Python icon while running, because the launcher `exec`s Python (`LSUIElement` may not carry over).

## Key behaviours and decisions (and why)
- **Routine:** set-time routines fire once a day (`state.json`) within `clock_window_min` (90) after the time, only while the user is present and only on their `days`. Nothing fires while the pet is busy or a question bubble is open. Every-N-minutes routines wait while the walk alert is active. Changing a routine's schedule re-arms it: it can fire again today at the new time, and its minutes count from the change.
- **Clipboard history is memory-only** and skips password-manager copies; it is never written to disk. Keep it that way.
- **System watch** (worried pet on low battery / full disk / high CPU) was offered and declined by the owner. Don't add it.
- **Original characters only:** no licensed characters or lookalikes. The caped hero is an original design (teal suit, gold cape, gold grapple line). Keep any new pet original.
- **Index:** filenames only. It scans every fixed drive but skips Windows, ProgramData, AppData, recycle bins, `.git`, `node_modules` and similar. **Cloud-sync folders are reparse points**: only mount points and symlinks are skipped (`SKIP_REPARSE_TAGS`), otherwise they vanish from the index. About 2.09M entries, 21 s warm scan, ~120 MB RAM, 20–80 ms searches.
- **Cobra deletes for real.** Never run Strike or `empty_recycle_bin` in tests; stub them.
- Explorer slowness (2026-11-04) was measured: the cat has no effect when idle or scanning. The slowdown came from a launch-time scan plus a ~12 GB Cobra delete hitting the disk together. That's why scans and deletes now use `background_io`.

## Testing approach (what worked)
- Scratch venv with PyQt6 (outside the repo). Offscreen for logic: `QT_QPA_PLATFORM=offscreen`.
- Real-desktop renders: grab the screen behind with `grabWindow` (glass windows hide themselves from capture), then composite `widget.grab()` on top. View the PNGs to check visuals.
- Stub `pet.tracker.detector.idle_seconds = lambda: 0.5`, or a real idle >20 s puts the cat into "away" in demo mode.
- Fake clock for routine: set `pet._now = lambda: datetime(...)`. Point `pet._state_path` at a scratch file.
- Fight test: stub `pet.cobra.execute_async` and `dc.empty_recycle_bin` to raise, run `pet._practice_fight()`, and snap at about 0.25 s (rise), right after the 2nd `cat.paw_down` (hit), about 2.6 s (fall) and about 3.6 s (dead). Snap windows include `pet._arena`. The cobra window is *not* hidden from capture, so the background grab also contains it and ghosts one frame behind the overlay. To judge sprite art, render `SpriteSheet(8, 1.0).cobra_frames()` to a sheet instead.
- Trip test: stub `dc.reveal_path` to record a timestamp, open the popup, `setText`, send Enter, sample `cat.x()` / `_trip_phase` every 100 ms; check delivery happens after the cat is back and the end x equals the start x.
- App test: `AppIndex(30)._load()` synchronously, then `search()`. Stub `dc.launch_app` to record targets; for a real check, launch Calculator via `shell:AppsFolder\Microsoft.WindowsCalculator_8wekyb3d8bbwe!App` and close only the new `CalculatorApp` process.
- Installer test: don't use `Start-Process -Wait`; it also waits for the cat and never returns. Use `-PassThru` and `$p.WaitForExit()`. A venv's `pythonw` is a launcher that spawns the base `pythonw`, so one cat shows as two processes (parent and child).
- Settings and pets: set `cfg.settings_path` to a scratch file **before** building `DesktopPet`, or the test reads and overwrites the user's real settings. Check all pets at all `SIZES` keep the ground line; render a frame sheet with `render_art` to judge art. Stunt: run `pet._stunt()` with `cat._move_timer` running, then check all phases, the top is reached and the pet lands at its start.
- Add-ons: stub `dc.start_screen_snip`, `dc.reveal_path`, `dc.open_with`, `dc.play_sound`, `dc.fullscreen_busy`; set `pet._now` for reminders, hats and summaries; fake a perch with `cat.perch_provider = lambda: (42, QRect(...))`. Clipboard events need ~0.5 s to arrive on Windows. Real hotkeys can be tested by registering them and sending Ctrl+Alt+key with `keybd_event`; stop the user's running pet first or the keys clash.
- Synthetic clicks: `QtTest.QTest.mouseDClick(pet.cat, ...)`; button clicks use `pet.bubble._button_rects()`.
- A Qt virtual method replaced by a lambda that returns a value crashes PyQt (0xC0000409). Use an event filter.
- Stop the user's running cat before live tests (pythonw with `desktop_cat` in its command line), then relaunch via the Desktop shortcut.
